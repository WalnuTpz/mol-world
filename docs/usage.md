# 使用指南

MolWorld 的公开页面用于查找、复制和下载表情包。访客可以提交图片，由管理员审核后发布。管理员从网站左上角 MolWorld 文字旁的图标进入控制台。

## 浏览和查找图片

首页默认打开“热门”的“随机”视图。点击“随机”重新抽取展示内容，点击“最热”按热度查看图片；热度是复制次数与下载次数之和。

“全部”显示已发布图库，并提供分页。在筛选栏点击“全部”会切换到“动图”，继续点击依次切换到“静态”和“全部”。“按名称”“最新”“最早”分别按名称、创建时间降序和创建时间升序排列。名称中的数字按数值排序，例如 `mol2` 排在 `mol10` 前。

在顶部搜索框输入关键词并提交，搜索会同时查找图片名称和标签。多个关键词用空格分隔，结果需要满足每一个关键词；例如 `开心 猫` 会匹配名称或标签中同时包含“开心”和“猫”的图片。搜索结果可切换“按名称”“最热”“最新”“最早”。点击图片卡片中的标签，也会以该标签发起搜索。

卡片显示最多四个标签，搜索会匹配图片保存的全部标签。列表底部提供“上一页”“下一页”和页码跳转。结果为空时，减少关键词数量或换用另一组词，可以扩大匹配范围。

## 复制和下载

点击图片卡片即可复制，卡片短暂高亮并显示操作结果。使用键盘时，按 Tab 聚焦卡片，再按 Enter 或空格复制。

浏览器支持图片剪贴板时，静态图片以图片形式复制。动图的复制结果取决于浏览器支持的格式：支持 GIF 剪贴板时复制动图，其余情况复制封面图，提示为“已复制封面图”。采用文本剪贴板时会提示“已复制图片（文本形式）”，内容为图片的 Data URL，适合接收这类文本的应用。需要原始动图文件时使用“下载”。

点击卡片内的“下载”，浏览器接收原文件后开始保存。下载按钮独立于卡片复制操作，键盘聚焦下载按钮后按 Enter 同样可用。右键或长按图片的浏览器保存菜单也可保存所见图片，预览位置对应缩略图。

剪贴板操作使用浏览器提供的权限和能力。出现复制失败提示时，检查当前页面的剪贴板权限，或改用“下载”。显示“操作过于频繁”时，等待冷却结束后再操作；默认复制间隔为 3 秒，下载间隔为 10 秒，随机切换间隔为 5 秒，管理员可在后台调整。

## 提交图片

1. 点击右上角“上传”，进入“添加表情包”。
2. 点击上传区域选择文件，也可以将文件拖入选择区域，或从剪贴板按 Ctrl+V 粘贴图片。一次提交一张，支持 JPG、PNG、GIF 和 WebP。当前大小上限显示在上传区域，默认 10 MiB，界面标为 MB。
3. 填写“图片名称”和“标签”。名称留空时显示为“未命名”；填写的名称会与现有图片名称比较，同名提交会提示修改名称。
4. 点击“提交”。出现“已提交，等待审核”后，图片进入管理员的审核列表，公开图库在审核通过后显示它。

标签使用空格分隔，也支持逗号、顿号和分号。保存时英文转为小写，保留汉字、英文字母、数字和下划线，重复标签合并。默认保存最多 8 个标签；含汉字的标签截取前 10 个字符，其余标签截取前 20 个字符。管理员可调整数量和长度，审核页显示最终保存结果。

“文件格式不支持或超过大小限制”表示需要重新选择相符的文件；“图片数据无效”或“图片内容与格式不符”表示图片解码或格式核对失败，可从图片编辑器重新导出后提交。“审核队列已过载”表示队列达到容量，等待管理员处理后再提交。访客上传间隔默认按同一 IP 60 秒、全站 5 秒执行，已登录管理员免除这两项间隔。

## 登录控制台

点击 MolWorld 文字旁的图标，在“管理员登录”中输入账号和密码，点击“登录”。登录成功后进入“表情包”页。已经登录时，点击同一图标直接进入控制台。

控制台有“表情包”“标签”“参数”“审核”“日志”“其他”六个入口。账号由站点部署者配置。多次登录错误会进入该 IP 的冷却窗口，页面显示相应提示；会话过期时重新登录即可继续管理。

在“其他”的“账号与退出”区域，点击“修改密码”，输入并确认新密码后保存。新密码长度为 4 至 64 个字符；保存成功后当前浏览器保持登录，其他已有会话结束。点击“退出登录”并确认，会结束当前浏览器的会话并返回首页。

## 审核新上传的图片

1. 打开“审核”，查看待审图片的预览、名称和标签。
2. 直接修改名称、标签。点击“保存”只保存编辑结果，图片继续留在审核列表。
3. 点击“通过”会同时保存当前编辑内容并发布。完成后该条从审核列表移除，可在“表情包”和公开页面查看。
4. 点击“删除”并确认，会移除这条待审记录。

可勾选多张图片，或使用“全选本页”，再执行“批量保存”“批量通过”“批量删除”。批量操作结束后显示成功与失败数量。出现“当前状态不可审核”时，表示该记录已经被处理；刷新列表即可查看当前队列。

## 编辑、隐藏和删除图库内容

“表情包”页管理已经进入图库的已发布与已隐藏图片。顶部搜索框可以按名称、标签、状态或类型查找。例如输入 `已隐藏 动图 猫`，会查找已隐藏的动图，并要求名称或标签包含“猫”。

点击某张图片的“修改”，编辑名称、标签，选择“已发布”或“已隐藏”，然后点击“保存”。“取消”恢复本次编辑前的内容。隐藏后，公开列表只展示其余已发布图片；该图片保留在管理页，可以再次修改为“已发布”。管理员仍可查看隐藏图片。

点击“删除”并确认会移除图片记录和标签关联。删除后的图片从管理页消失，恢复需要站点的数据库与媒体备份，具体步骤见[恢复备份](operations.md#恢复备份)。隐藏适用于保留图片并暂停公开，删除适用于移除图库记录。

勾选图片或“全选本页”后，可以执行“批量发布”“批量隐藏”“批量清零”“批量删除”。其中“批量清零”将所选图片的复制、下载次数及其历史每日交互计数归零。批量操作的结果显示为“成功 N / 失败 N”，刷新后的列表反映已经完成的修改。

## 整理标签

打开“标签”查看标签名、数字 ID 和关联数量。使用搜索框定位标签，点击“按数量”或“按名称”切换排序字段，点击“升序”或“降序”切换方向。

- **重命名**：点击标签行的“重命名”，输入新名称后“保存”。所有关联图片继续使用这条标签，并显示新名称。
- **合并**：在上方输入合并来源和合并目标，可以使用现有标签名或 ID，点击“合并”并确认。来源的图片关联转到目标，重复关联合并，来源标签被删除。
- **解除**：移除该标签与全部图片的关联，保留标签本身。
- **删除**：删除该标签以及它与全部图片的关联。图片记录和媒体继续保留。

新标签可在上传、审核或编辑图片时填写，保存图片时建立对应标签。

## 阅读流量与热度

在“其他”的“流量与热度”中，选择最近 3 天、7 天、30 天或全部，并使用“刷新数据”重新读取统计。日期按 UTC 划分，每日边界对应北京时间 08:00。

| 视图 | 含义 |
| --- | --- |
| 热门 Top 30 | 所选时间范围内，现存图片的复制与下载次数之和排行；包含已发布和已隐藏图片 |
| 访问趋势 | 首页路径的页面访问次数 PV，涵盖热门、全部、搜索及翻页 |
| 独立访客 | 按浏览器身份和 UTC 日期去重的每日 UV |
| 热度总和 | 从所选时间范围第一天起累计的交互次数 |
| 每日新增 | 当天增加的复制与下载次数 |

同一浏览器当天重复访问会增加 PV，UV 仍计一次；清除 Cookie、更换浏览器或设备会产生新的访客身份。UV 衡量浏览器身份，从新统计启用后开始记录；升级前的日期保留原有 PV，UV 为 0。页面预取、上传页、后台以及单独读取图片均不计入首页 PV。

复制在浏览器完成剪贴板操作并确认后计数，图片形式和文本形式均包括在内。下载在服务端完整输出文件并确认后计数。在服务端读完整个文件前中断下载，计数保持原值；重复使用同一操作凭据只计一次。右键保存图片走普通媒体读取流程，不增加站内下载计数。

图片删除后，历史交互继续保留在每日曲线中，Top 30 只显示仍存在的图片。因此，日曲线合计与当前图库的热度合计可能不同。“热度总和”按当前选择的时间范围重新累计，例如切换到“最近 7 天”时从这七天的起点开始相加。

## 调整参数和查看操作记录

在“参数”修改上传容量、审核队列、分页、随机池、标签规则及交互间隔，点击“保存修改”应用修改。服务端后续请求读取新值，已经打开的页面重新加载后采用新的界面参数。修改会话有效期会用于后续签发的会话。“取消修改”撤回当前表单尚未保存的编辑；“恢复默认”在确认后将全部参数保存为默认值。各参数的默认值、范围和生效规则见[配置参考](configuration.md)。

在“日志”选择时间范围，输入操作类型、消息或目标 ID 搜索记录。“导出 CSV”导出符合当前时间范围和搜索条件的记录；“清理日志”删除所选时间范围内的日志，范围由时间选择器决定。

“其他”的“资源维护”提供“缺图检查”和“清理孤儿文件”。检查范围是图库的原图与缩略图目录，结果显示数据库中指向缺失文件的原图、缩略图引用数量，以及磁盘上没有图片记录引用的孤儿文件数量。点击“清理孤儿文件”并确认，会从磁盘直接删除这些孤儿文件。“全站热度清零”会清零全部图片及历史每日交互计数，访问次数和独立访客统计保留。

操作提示“未登录”或“会话已失效”时，重新从左上角图标登录。提示“资源不存在”时，刷新列表确认图片当前状态。批量操作出现部分失败时，根据刷新后的列表处理剩余记录。
