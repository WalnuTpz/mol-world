# Bundled fonts

Space Grotesk and Noto Sans SC are distributed under the SIL Open Font License 1.1. Their license notices are included alongside the WOFF2 files. These are the existing Google Fonts subsets and weights used by the application, copied unchanged from the previously generated Next.js font assets. `src/app/fonts.css` retains the subset unicode ranges and fallback metrics; browsers request only the needed subsets.

Upstream families and license sources:

- https://github.com/google/fonts/tree/main/ofl/spacegrotesk
- https://github.com/google/fonts/tree/main/ofl/notosanssc

Fonts are served locally. Building the application does not fetch fonts from Google. When changing font files, update the CSS declarations and retain the applicable license notices.
